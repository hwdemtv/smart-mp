# WeWrite - 微信公众号写作Obsidian 插件

> 维护说明：原作者 Learner Chen 近期开源仓库更新较少，本 fork 由 hwdemtv 持续维护，修复兼容问题并优化性能，保留原作者署名。

### 本次 fork 的背景与修复
- 原版维护节奏较慢，微信草稿编辑态会在列表中插入空行/空序号。
- 预览性能欠佳：Shadow DOM + 双重渲染链路，切换/输入时卡顿。
- 主题获取不稳定：远程主题源不易访问，样式选择受限。

### 我们的改动（持续迭代中）
- **排版增强**:
    - **显示图片说明 (Image Captions)**: 支持自动将图片的 `Alt` 文本转换为微信风格的下方说明文字。
    - **链接转脚注**: 自动将文中超链接提取为文末脚注，完美适配微信公众号阅读体验。
    - **首行缩进**: 支持一键开启中文段落首行缩进 (2em)。
    - **嵌入字数统计**: 可选在文章开头嵌入“全文约 xx 字 · 预计阅读 xx 分钟”的统计信息。
    - **代码块优化**: 增加 Mac 风格代码块标题栏（显示语言名称），支持多种高亮主题切换。
    - **细节优化**: 优化分割线 (`---`) 为文艺风格居中符号，表格支持移动端横向滚动，引用块(Blockquote)美化。
    - **字号调整**: 支持在设置中直接切换正文字号 (14px - 17px)。
- **样式隔离**: 采用 CSS 命名空间隔离技术，防止 Obsidian 全局主题污染微信预览效果，确保“所见即所得”。
- **手机预览模式**: 新增手机视图 (Mobile View) 切换按钮，一键模拟 375px 手机屏幕宽度的显示效果。
- **界面汉化**: 插件设置界面、工具栏提示完全中文化，更符合国人使用习惯。
- **高精度滚动同步**: 升级为基于标题锚点 (Heading-Anchor) 的同步算法，彻底解决长文章中图片导致的对齐偏移问题。
- **固定布局优化**: 预览界面的工具栏与文章属性面板实现**置顶固定 (Sticky)**，滚动正文时头部不再消失。
- **快捷键支持**: 新增 `Toggle Scroll Sync` 命令，支持自定义快捷键一键启停同步。
- 列表兼容：清理空节点，避免微信编辑态插入空 `<li>` 并重排编号。
- 性能优化：移除 Shadow DOM，简化渲染链路，减少大文件渲染卡顿。
- 主题增强：切换主题下载源到当前仓库，集成 NoteToMP 全套主题并完成类名适配。
- 安装指引：新增 `INSTALL-OBSIDIAN.md`，提供本地安装/测试包（wewrite-dev）说明。
- 插件标识：为避免与原版冲突，当前包使用 `id: wewrite-plus` / `name: WeWrite+`（社区上架前可按需调整为最终标识）。

## 📌 新功能指引

### 🖼️ 图片说明 (Caption)
支持自动将 Markdown 图片的 `Alt` 文本转换为微信风格的灰色说明文字。

**示例**：
```markdown
![这是架构图](assets/arch.png)
```
效果：图片下方居中显示灰色小字 **“这是架构图”**。

**注意**：为了美观，系统会自动**忽略**以下情况：
- 文件名（包含后缀，如 `image.png`）
- 过短文本（少于2个字符）
- Obsidian 默认粘贴名称（`Pasted image...`）

*需在设置 -> 排版增强 中开启“显示图片说明”。*

## 概述

WeWrite 是一款将 Obsidian 的强大功能与微信公众号编辑需求完美契合的插件。它使您能够通过简单的操作，将精心撰写的 Markdown 笔记一键转化为精美的微信公众号文章。它旨在将笔记渲染并发布到微信公众号平台，同时集成 AI 写作辅助功能，使 Obsidian 成为微信公众号内容的强大写作工具。不依赖外部的图床或第三方平台。

## 功能

### Obsidian 特色内容渲染为微信公众号格式
- **Markdown 渲染**：支持标准 Markdown 内容。
- **Excalidraw**：支持直接嵌入 Excalidraw 插件的图表。
- **Mermaid**：支持 Mermaid 图表。
- **LaTeX**：支持 LaTeX 公式。
- **Callout & Admonition**：支持 Obsidian 原生的 Callout 和 Admonition。
- **代码高亮**：支持代码块和行内代码。
- **图标**：支持 Obsidian 图标、Iconize 插件以及 Remix 图标在 Markdown 内容中的使用。
- **Charts**：支持 Obsidian Charts插件的内容。
- **PDF++**：支持 Obsidian PDF++ 插件中的笔记和图片。
- **嵌套笔记**：支持在笔记中嵌入其它笔记的渲染。
- **链接与脚注**：将链接和脚注转换为微信公众号格式。

### AI 写作辅助
- **内容润色**：使用 AI 优化文章内容。
- **双语翻译**：支持中英文双向翻译。
- **Mermaid 生成**：自动生成 Mermaid 图表。
- **LaTeX 生成**：自动生成 LaTeX 公式。
- **同义词建议**：为选中的词语提供同义词替换建议。
<video controls src="ai-aided-writing.mp4" title="AI 写作辅助"></video>

### 微信公众号集成
- **素材管理**：管理微信公众号素材，包括图片、音频和视频。
- **草稿管理**：创建、预览和发布微信公众号文章。
- **账号管理**：支持切换多个微信公众号账号。

### 其他功能
- **主题管理**：支持自定义主题样式。
- **实时预览**：提供文章实时预览功能。

## 安装指南

1. 在 Obsidian 中打开 **设置**。
2. 进入 **社区插件** 页面。
3. 搜索 "WeWrite"。
4. 点击 **安装** 并启用插件。

## 使用说明
### 配置

这是一个简单的示例配置。
[配置简介](settings.md)

更多的使用方法细节，我们未来在公众号中会发布一系列教程。

### 基本用法
1. 使用编辑器的右键菜单访问 AI 写作辅助功能（例如，内容润色、翻译等）。
2. 通过右键菜单或命令面板访问 WeWrite 功能。
3. 在右侧预览器中设置草稿属性（例如，标题、摘要、封面图片等）。
4. 使用 AI 辅助一键生成摘要和封面图片。
5. 将草稿发送到微信公众号。
6. 自定义主题可以作为普通笔记（`.md` 文件）进行管理。

### 微信公众号集成
1. 使用 **素材管理** 上传和管理素材。
2. 使用 **草稿管理** 删除、预览、批量发布和发布草稿。
