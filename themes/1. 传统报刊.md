# 1. 风格特点

- 以中文宋体为主要字体
- 排版中规中矩
- 泛黄的报纸底色，非纯黑色的字体
- 不做多余的修饰
- 基本使用默认的风格

```CSS
:root {
	 --article-font-family: "FZBaoSong-Z04S", "SimSun", "Songti SC", "NSimSun", serif;
	 --smart-mp-text: rgba(0,  0,  0, 0.8);
	 --smart-mp-bg: #f0e6d2;
	 --article-max-width: 900px;
	 --blockquote-background-color: #f5f5dc;
	 --code-background:  rgba(255, 255, 255, 0.4);
	 --code-section-background-color: var(--code-background);
}

/* 段落样式 - 防止数字被误认为标题 */
.smart-mp p {
  border-left: none !important;
  padding-left: 0 !important;
  margin: 1em 0 !important;
}

/* 高亮文本样式 */
.smart-mp mark, .smart-mp .highlight {
  background-color: #ffeb3b !important;
  color: #333 !important;
  padding: 0 2px !important;
  border-radius: 3px !important;
}

/* 行内代码样式 */
.smart-mp code {
  background-color: rgba(0, 0, 0, 0.05) !important;
  padding: 2px 4px !important;
  border-radius: 3px !important;
  font-family: var(--code-font-family, monospace) !important;
  font-size: 0.9em !important;
  color: #e83e8c !important;
}

/* 引用块样式 */
.smart-mp blockquote {
  background-color: var(--blockquote-background-color, #f5f5dc) !important;
  padding: 1em 1.5em !important;
  border-left: 4px solid #8b7355 !important;
}

/* 分隔符样式 */
.smart-mp-hr-replacement {
  margin: 30px 0 !important;
  height: 2px !important;
  background: linear-gradient(to right, transparent, rgba(0, 0, 0, 0.3), transparent) !important;
  font-size: 0 !important;
  border: none !important;
}
```
