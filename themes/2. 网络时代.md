# 1. 风格特点

- 以无衬线为主要字体
- 排版中规中矩
- 基本使用默认的风格

```CSS
:root {
	 --article-font-family: "Helvetica Neue", "PingFang SC", "Microsoft YaHei", "Arial", sans-serif;
	 --wewrite-text: #1e3a8a;
	 --u-text-decoration-style:wavy;
	 --article-max-width: 900px;
	 --blockquote-background-color: #f0f9ff;
}

.wewrite blockquote {
	border-left-width:8px;
	border-left-color:#1e3a8a;
	background-color: var(--blockquote-background-color, #f0f9ff) !important;
	padding: 1em 1.5em !important;
}

/* 段落样式 - 防止数字被误认为标题 */
.wewrite p {
  border-left: none !important;
  padding-left: 0 !important;
  margin: 1em 0 !important;
}

/* 高亮文本样式 */
.wewrite mark, .wewrite .highlight {
  background-color: #ffeb3b !important;
  color: #333 !important;
  padding: 0 2px !important;
  border-radius: 3px !important;
}

/* 行内代码样式 */
.wewrite code {
  background-color: rgba(0, 0, 0, 0.05) !important;
  padding: 2px 4px !important;
  border-radius: 3px !important;
  font-family: var(--code-font-family, monospace) !important;
  font-size: 0.9em !important;
  color: #e83e8c !important;
}

/* 分隔符样式 */
.wewrite-hr-replacement {
  margin: 30px 0 !important;
  height: 2px !important;
  background: linear-gradient(to right, transparent, #1e3a8a, transparent) !important;
  font-size: 0 !important;
  border: none !important;
}
```
