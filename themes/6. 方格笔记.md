# 1. 风格特点

```css
:root{
      --article-background-image:
   linear-gradient(to right, rgba(0, 0, 0, 0.05) 1px, transparent 1px),    linear-gradient(to bottom, rgba(0, 0, 0, 0.05) 1px, transparent 1px); 
  --article-background-color: #f5ecd9;
  --smart-mp-text: #3c2f1c;
  --article-background-size: 30px 30px;
  --blockquote-background-color: #f9f9f9;
  
}

```

# 2. 引用
```css
/* 引用块样式 */
.smart-mp blockquote {
  display: inline-block;
  padding: 4px;
  background: #000; /* 边框色 */
  transform: skew(-20deg, -1deg); /* 倾斜一点点 */
}
.smart-mp .blockquote-inner {
  background: var(--blockquote-background-color, #f9f9f9) !important; /* 背景色 */
  padding: 20px;
  transform: skew(2deg, 1deg); /* 抵消外层倾斜，让内容不歪 */
}

/* 标准引用块样式（非倾斜版本） */
.smart-mp blockquote:not(.blockquote-inner) {
  background-color: var(--blockquote-background-color, #f9f9f9) !important;
  padding: 1em 1.5em !important;
  border-left: 4px solid #3c2f1c !important;
  display: block;
  transform: none;
}

/* 段落样式 - 防止数字被误认为标题 */
.smart-mp p {
  border-left: none !important;
  padding-left: 0 !important;
  margin: 1em 0 !important;
}

/* 高亮文本样式 */
.smart-mp mark, .smart-mp .highlight {
  background-color: #ffeb3b !important;
  color: #333 !important;
  padding: 0 2px !important;
  border-radius: 3px !important;
}

/* 行内代码样式 */
.smart-mp code {
  background-color: rgba(0, 0, 0, 0.05) !important;
  padding: 2px 4px !important;
  border-radius: 3px !important;
  font-family: var(--code-font-family, monospace) !important;
  font-size: 0.9em !important;
  color: #e83e8c !important;
}

/* 分隔符样式 */
.smart-mp-hr-replacement {
  margin: 30px 0 !important;
  height: 2px !important;
  background: linear-gradient(to right, transparent, #3c2f1c, transparent) !important;
  font-size: 0 !important;
  border: none !important;
}
```
